# Extras

Fragmentos sueltos que **no** forman parte del tema. Shopify ignora esta
carpeta al sincronizar, así que puedes guardar aquí código para pegar a mano.

- `slider-liquid-personalizado.liquid` — slider de banners para pegar dentro
  de un bloque **"Liquid personalizado"** de cualquier tema (Helio, Dawn, etc.).
  No necesita crear archivos de sección. Las instrucciones están en los
  comentarios del propio archivo.

Si prefieres el slider como sección de verdad (con sus ajustes en el
personalizador), usa `sections/hero-slider.liquid` de la raíz del repo.
